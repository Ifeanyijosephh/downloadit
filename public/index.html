FAQ

Is it free?

Yes. DownloadIt is free to use with no ads and no premium tier.

Do you store my links?

No. Links are handled in memory for the duration of the request and then discarded.

Which formats can I save?

MP4 video, and MP3 audio where the server has ffmpeg available.

Can I download private videos?

No. Only public content that the platform allows to be accessed without a login.
